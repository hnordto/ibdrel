Likelihood table

Displays the pairwise relationship prediction for the inputted IBD sharing.

Each row corresponds to a predicted genetic relationship class. Columns:

  • Rank
  • Outlier detection: Whether the input matches the general pattern observed in simulated data, in terms of total sharing and number of segments:
    • ✅ if input is not an outlier.
    • ❌ if input is an outlier.
  • Class: Name of the relationship.
  • C: Confidence score of the relationship:
    • Normalized: Scores normalized to sum to 1.
    • Unnormalized: Raw likelihood estimates, reported on natural logarithmic scale.

The confidence score quantifies the model’s belief in each class given the input data. It should not be interpreted as a true probability estimate of the class, but rather used as a coarse estimate of how likely each class is, which can be used for comparisons between classes.

Additional columns display additional information about the class if applicable, such as kappa coefficients, kinship coefficients, and relationship degree.

Tab panels

Prediction is carried out at different resolutions, with distinct sets of predicted classes:

  • Ped: Pedigree relationships with sex-specific ancestral paths up to equivalence. Equivalent relationships are those that are indistinguishable in terms of pairwise IBD sharing. One representative for each equivalence group is displayed.
  • Rel: Pedigree relationships without sex-specific ancestral paths up to equivalence. Equivalent relationships are those that are indistinguishable in terms of pairwise IBD sharing. One representative for each equivalence group is displayed.
  • Kap: The kappa coefficients for the relationship. These are the expected probabilities of sharing 0, 1, or 2 alleles IBD at a locus.
  • Kin: The kinship coefficient for the relationship. This is the probability that two alleles chosen randomly from the two individuals are IBD.
  • Deg: The relationship degree.
