Input

IBDrel takes identity by descent (IBD) segment lengths for a single pairwise genetic match as input. The lengths are measured in centiMorgans (cM). Three input formats are accepted:

  • Free text: Manually enter segment lengths into a text field, one segment length per line.
  • File upload: Upload a text file (.txt) with one segment length per line.
  • Simulate example: Simulate an example for any pedigree relationship included by default in IBDrel using ibdsim2.
